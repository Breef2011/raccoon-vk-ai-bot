# Енот Валера — чат-бот сообщества «Еноты» во ВКонтакте

Чат-бот для сообщества ВКонтакте, который отвечает на вопросы пользователей с помощью официального **GigaChat API**. Бот представляет сообщество «Еноты», консультирует по енотам, опирается на локальную базу знаний и мягко предлагает форму для связи с менеджером, когда точного ответа нет.

## Возможности

- Приём и отправка сообщений сообщества ВКонтакте через Long Poll API.
- Ответы через GigaChat API с автоматическим получением и обновлением OAuth-токена.
- Отдельный системный промпт с ролью Енота Валеры.
- Локальная база знаний о еноте-полоскуне в Markdown.
- Простой поиск по разделам базы знаний: пока база помещается в лимит, модель получает её целиком; при росте базы выбираются релевантные разделы.
- Память диалога на пользователя с ограничением длины и времени жизни.
- Команды `помощь`, `сброс`, `контакты`.
- Ответы на длинные сообщения частями.
- Проверка доступов командой `python main.py --check`.
- Секреты только в `.env`; в репозитории лежит безопасный `.env.example`.

## Требования

- Python 3.10 или новее.
- Сообщество ВКонтакте с включёнными сообщениями и Long Poll API.
- Доступ к GigaChat API и Authorization Key из GigaChat Studio.
- Интернет и возможность подключиться к `api.giga.chat` и OAuth-сервису GigaChat.

## Быстрый старт

### 1. Установить зависимости

Windows (PowerShell):

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env
```

### 2. Заполнить `.env`

Скопируйте `.env.example` в `.env` и вручную добавьте свои значения. Обязательны только `VK_GROUP_TOKEN` и `GIGACHAT_CREDENTIALS`, остальные переменные необязательны. Подробное описание — в разделе [Переменные окружения](#переменные-окружения).

### 3. Проверить доступы

```bash
python main.py --check
```

Команда проверяет получение токена GigaChat, доступ к списку моделей и доступ к сообществу ВКонтакте. Она не отправляет сообщения и не выводит секреты.

### 4. Запустить бота

```bash
python main.py
```

Остановка — `Ctrl+C`.

## Получение доступов

### GigaChat API

1. Зарегистрируйтесь в GigaChat Studio для разработчиков: <https://developers.sber.ru/>.
2. Создайте проект или приложение и подключите GigaChat API.
3. Выберите область доступа (`scope`):
   - `GIGACHAT_API_PERS` — для физических лиц;
   - `GIGACHAT_API_B2B` — для юридических лиц с подпиской;
   - `GIGACHAT_API_CORP` — для юридических лиц по модели pay-as-you-go.
4. Получите **Authorization Key**. Это уже готовая строка Base64 вида `Client ID:Client Secret`. Именно она указывается в `GIGACHAT_CREDENTIALS`.
5. Не путайте Authorization Key с отдельным `Client Secret`: секрет не нужно вставлять в код или пересылать кому-либо.

Официальная документация GigaChat API находится в папке проекта `Gigachat_api/`. По документации:

- базовый адрес API с 17 февраля 2026 года — `https://api.giga.chat`;
- чат-запрос — `POST https://api.giga.chat/v1/chat/completions`;
- OAuth-токен — `POST https://ngw.devices.sberbank.ru:9443/api/v2/oauth`;
- access token живёт около 30 минут; бот получает и обновляет его сам.

### Сообщество ВКонтакте

1. Создайте сообщество или откройте существующее.
2. В разделе **Управление → Настройки → Работа с API** создайте ключ доступа.
3. Выдайте ключу право **«Сообщения сообщества»**. Для отправки сообщений и Long Poll этого достаточно.
4. В настройках сообщества включите **«Сообщения сообщества»**.
5. В разделе **Long Poll API** включите Long Poll и событие **«Входящие сообщения»**. Рекомендуется использовать актуальную версию API.
6. Скопируйте ключ в `VK_GROUP_TOKEN`.
7. Числовой ID сообщества можно посмотреть в настройках сообщества или получить через VK API. Он необязателен: если `VK_GROUP_ID` не задан, бот определит ID по токену.

Токен сообщества — секрет. Если он попал в переписку, скриншот или репозиторий, отзовите его в настройках сообщества и создайте новый.

## Переменные окружения

Все значения задаются в `.env`. Файл `.env` исключён из Git и не должен публиковаться.

| Переменная | Обязательна | Значение по умолчанию | Назначение |
|---|---:|---|---|
| `VK_GROUP_TOKEN` | да | — | Ключ доступа сообщества ВКонтакте с правом «Сообщения сообщества». Нужен для Long Poll и отправки ответов. |
| `GIGACHAT_CREDENTIALS` | да | — | Authorization Key из GigaChat Studio (Base64 `Client ID:Client Secret`). Нужен для получения access token. |
| `VK_GROUP_ID` | нет | определяется по токену | Числовой ID сообщества. Укажите, если бот не может определить его автоматически. |
| `VK_TRANSPORT` | нет | `auto` | Как получать сообщения: `auto` — Long Poll, а при выключенных событиях опрос диалогов; `longpoll` — только Long Poll; `polling` — только опрос. |
| `GIGACHAT_SCOPE` | нет | `GIGACHAT_API_PERS` | Область доступа GigaChat: `GIGACHAT_API_PERS`, `GIGACHAT_API_B2B` или `GIGACHAT_API_CORP`. |
| `GIGACHAT_MODEL` | нет | `GigaChat-2` | Модель GigaChat. Можно указать `GigaChat-2-Lite`, `GigaChat-2-Pro`, `GigaChat-2-Max`, если они доступны вашему тарифу. |
| `GIGACHAT_BASE_URL` | нет | `https://api.giga.chat/v1` | Базовый адрес API. Менять не нужно, если вы не используете собственный прокси. |
| `GIGACHAT_OAUTH_URL` | нет | `https://ngw.devices.sberbank.ru:9443/api/v2/oauth` | Адрес OAuth-сервиса для получения access token. |
| `GIGACHAT_VERIFY_SSL` | нет | `true` | Проверять TLS-сертификат. Отключайте только для локальной диагностики: это снижает безопасность. |
| `GIGACHAT_CA_BUNDLE` | нет | — | Путь к PEM-файлу с корневым сертификатом, если нужна своя цепочка доверия. Имеет приоритет над `GIGACHAT_VERIFY_SSL`. |
| `GIGACHAT_TEMPERATURE` | нет | `0.55` | Температура генерации от 0 до 2. Ниже — стабильнее ответы, выше — разнообразнее. |
| `GIGACHAT_MAX_TOKENS` | нет | `800` | Максимальное число токенов в ответе. |
| `CONTACT_FORM_URL` | нет | — | Публичная ссылка на форму для связи (Яндекс Формы, Google Forms, VK-форма и т. п.). Бот предлагает её в подходящий момент. Если пусто — предлагает написать в сообщения сообщества. |
| `MAX_HISTORY_MESSAGES` | нет | `12` | Сколько последних сообщений (вопросов и ответов) хранить в памяти на пользователя. Значение приводится к чётному. |
| `DIALOG_TTL_MINUTES` | нет | `180` | Через сколько минут неактивный диалог очищается. |
| `LOG_LEVEL` | нет | `INFO` | Уровень логов: `DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`. |

Пример заполнения (значения вымышленные, не используйте их):

```dotenv
VK_GROUP_TOKEN=<ваш_токен_сообщества>
GIGACHAT_CREDENTIALS=<ваш_authorization_key>
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat-2
CONTACT_FORM_URL=<ссылка_на_вашу_форму>
```

В реальном `.env` должны быть только ваши настоящие значения. Не добавляйте `.env` в Git.

## Как работает бот

1. `main.py` загружает настройки из `.env`, базу знаний и системный промпт.
2. `VkBot` подключается к Long Poll API сообщества и слушает входящие сообщения.
3. Для каждого пользователя хранится отдельная история диалога в памяти.
4. На вопрос пользователя `DialogService` собирает запрос:
   - системный промпт Енота Валеры;
   - релевантная часть базы знаний;
   - история диалога;
   - новый вопрос.
5. `GigaChatClient` получает access token по Authorization Key, кэширует его и вызывает `POST /v1/chat/completions`.
6. Ответ отправляется пользователю. Длинные ответы делятся на несколько сообщений.
7. Если GigaChat временно недоступен, бот делает несколько повторов, а затем отправляет вежливое сообщение с предложением написать менеджеру.

### Команды

- `помощь` или `/help` — краткая справка.
- `сброс` или `/reset` — очистить историю диалога.
- `контакты` или `/contacts` — показать форму для связи или предложить написать в сообщения сообщества.
- `/start` — приветствие.

## Системный промпт и база знаний

### Системный промпт

Файл: `prompts/system_prompt.txt`.

В промпте описаны:

- роль и характер Енота Валеры;
- мужской род и доброжелательный стиль;
- запрет на посторонние темы и мягкий возврат к енотам;
- запрет на выдумывание фактов;
- правило предлагать менеджера и форму для связи, если точного ответа нет;
- стиль ответов для ВКонтакте.

Не удаляйте плейсхолдер `{{KNOWLEDGE_BASE}}`: в него подставляется база знаний. Плейсхолдер `{{CONTACT_FORM}}` заменяется на ссылку из `CONTACT_FORM_URL` или на безопасную инструкцию написать в сообщения сообщества. Если удалить `{{KNOWLEDGE_BASE}}`, бот не запустится и сообщит об ошибке.

### База знаний

Файл: `knowledge/raccoon_knowledge.md`.

База собрана по статье «Енот-полоскун» в русской Википедии: <https://ru.wikipedia.org/wiki/Енот-полоскун>. Разделы размечены заголовками `##`. При запуске бот читает файл, а на каждый вопрос подставляет базу знаний в системный промпт.

- Пока база целиком помещается в лимит (20 000 символов), модель получает её полностью.
- Если база вырастет, `KnowledgeBase` выберет наиболее релевантные вопросу разделы по ключевым словам, а разделы «Кратко о виде» и «Границы базы знаний» добавит всегда.
- Чтобы обновить знания, отредактируйте Markdown и перезапустите бота.
- Добавляйте только проверенные факты. Если данных нет, лучше прямо указать это в разделе «Границы базы знаний», чем позволять модели додумывать.

## Форма для связи

Укажите публичную ссылку в `CONTACT_FORM_URL`. Бот предлагает форму, когда:

- пользователь спрашивает о покупке, наличии, доставке, бронировании или услугах;
- в базе знаний нет точного ответа;
- пользователю нужен менеджер.

Если `CONTACT_FORM_URL` не задан, бот предложит написать в сообщения сообщества. Ссылка не выдумывается моделью: она подставляется из настроек.

## Безопасность

- Реальные ключи и токены хранятся только в `.env`.
- `.env` добавлен в `.gitignore`; в репозиторий попадает только `.env.example` без значений.
- В коде нет реальных токенов, ключей и паролей.
- Бот не выводит access token в логи и сообщения пользователю.
- Текст сообщений пользователей не пишется в логи; для диагностики используются ID и коды ошибок.
- Ограничьте доступ к файлу `.env` на сервере.
- При компрометации токена ВКонтакте отзовите ключ в настройках сообщества, а ключ GigaChat пересоздайте в Studio.
- Не публикуйте скриншоты настроек с открытыми ключами.

## Диагностика

### `Ошибка конфигурации: Не задана обязательная переменная ...`

Файл `.env` отсутствует или в нём не заполнены `VK_GROUP_TOKEN` / `GIGACHAT_CREDENTIALS`. Скопируйте `.env.example` в `.env` и заполните значения.

### `SSL: CERTIFICATE_VERIFY_FAILED`

На некоторых системах не установлены российские корневые сертификаты. Варианты:

1. Установить сертификаты по инструкции GigaChat API (файлы `russian_trusted_root_ca_pem.crt` и `russian_trusted_sub_ca_pem.crt`).
2. Указать путь к PEM-файлу в `GIGACHAT_CA_BUNDLE`.
3. Только для локальной диагностики временно установить `GIGACHAT_VERIFY_SSL=false`. Не используйте это в продакшене: отключение проверки TLS делает соединение уязвимым.

В этом проекте сертификаты Минцифры уже скачаны в `certs/`, а общий bundle с корневыми сертификатами `certifi` собран в `certs/ca_bundle.pem`. В `.env` достаточно указать:

```env
GIGACHAT_CA_BUNDLE=certs/ca_bundle.pem
```

Путь можно задавать относительным — он считается от корня проекта.

### Long Poll не запускается

Ошибка `longpoll for this group is not enabled` означает, что в сообществе выключен Long Poll API. Включите его: «Управление» → «Сообщения» → «Long Poll API» (и «Сообщения сообщества»), затем перезапустите бота.

Если включить события Long Poll не получается (VK API принимает настройку, но `message_new` остаётся выключенным), бот с `VK_TRANSPORT=auto` автоматически перейдёт на опрос диалогов через `messages.getConversations`. Это работает без дополнительных настроек сообщества, но создаёт регулярные запросы к VK API. Для принудительного выбора режима укажите `VK_TRANSPORT=longpoll` или `VK_TRANSPORT=polling`.

### GigaChat отвечает `401` или `403`

- Проверьте, что `GIGACHAT_CREDENTIALS` — это именно Authorization Key из Studio, а не Client Secret.
- Проверьте `GIGACHAT_SCOPE`: он должен соответствовать типу вашего доступа.
- Убедитесь, что у приложения есть доступ к выбранной модели.

### GigaChat отвечает `429`

Превышен лимит запросов. Бот сам делает паузы и повторяет запрос, но при постоянном превышении уменьшите нагрузку или проверьте тариф.

### ВКонтакте отвечает `901`

Нет доступа к сообщениям. Включите «Сообщения сообщества», проверьте право «Сообщения сообщества» у ключа и заново создайте токен при необходимости.

### ВКонтакте отвечает `100`

Неверный параметр, чаще всего `VK_GROUP_ID`. Удалите `VK_GROUP_ID` из `.env`, чтобы бот определил ID по токену, или укажите правильный числовой ID.

### Бот запускается, но не отвечает

- Проверьте, что в сообществе включены сообщения и Long Poll API.
- В Long Poll API должно быть включено событие «Входящие сообщения».
- Убедитесь, что вы пишете сообществу, а не в личный диалог от имени сообщества.
- Посмотрите логи: при ошибке Long Poll бот пишет причину и переподключается.
- Не запускайте два экземпляра бота с одним токеном: они будут мешать друг другу получать события.

### `python main.py --check` не выводит секреты

Так и должно быть. Команда показывает только статус, название сообщества, его ID и список доступных моделей.

## Ограничения

- История диалогов хранится в оперативной памяти и очищается при перезапуске или по `DIALOG_TTL_MINUTES`.
- Бот не обрабатывает фото, видео, документы и голосовые сообщения — только текст.
- Бот не заменяет ветеринара и не даёт медицинских назначений.
- Качество ответов зависит от базы знаний и выбранной модели GigaChat.
- Для работы нужен доступ к внешним API; при недоступности GigaChat бот сообщает об этом пользователю.
- Один экземпляр бота рассчитан на одно сообщество.
